## 🎯 使用方式

### 快速开始
```bash
# 安装
pip install -e .

# 处理单个文件
lumina process ./document.md

# 处理目录（递归）
lumina process ./notes --recursive

# 增量处理（只处理变化的文件）
lumina process ./notes --incremental

# 指定输出目录
lumina process ./notes --output ./output

# 指定质量阈值
lumina process ./notes --threshold 0.9
```

### Python API
```python
from lumina import Harness, HarnessConfig

# 创建配置
config = HarnessConfig(
    max_iterations=3,
    quality_threshold=0.8,
    output_dir="./my_notes",
    use_cache=True,
    incremental=True,
    parallel=True,
)

# 执行处理
harness = Harness(config)
report = harness.run("./source_files")

# 查看结果
print(f"处理文件数: {report['statistics']['processed_files']}")
print(f"平均得分: {report['statistics']['avg_score']:.2f}")
print(f"缓存命中率: {report['statistics']['cache_hit_rate']:.1%}")
```

## 🎯 核心设计理念

1. **以用户为中心**：降低使用成本，提升体验
2. **成本最优**：缓存、增量处理大幅降低 LLM 成本
3. **质量优先**：迭代修复确保输出质量
4. **可扩展**：模块化设计支持灵活扩展
5. **可解释**：完整历史记录，决策过程透明
6. **高可靠**：容错机制确保稳定运行
